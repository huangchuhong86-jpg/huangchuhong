# 上架字段参考

## 商品识别

- 商品名称：用产品类型、核心功能、可验证特征、规格和数量组成自然英文标题，避免关键词堆砌。
- 商品类型：按实际功能选择，不因词语相似选择实质不同的类别。
- 品牌：有真实品牌时与包装和授权一致；无品牌时使用 `Generic` 并勾选无品牌。
- 制造商：填写真实制造商法定名称；未知时不得猜测。
- 产品亮点：仅在字段需要且标题较短时填简短短语，不粘贴完整标题。

## 内容

- 五点描述分别覆盖包装内容、核心功能、使用方式或控制、经核实的材质/配方特征、适用场景与注意事项。
- 不写绝对效果、医疗功效、保证性用语、竞品名称、联系方式、价格或配送承诺。
- 搜索词使用前台文案未覆盖的相关同义词；不要为了填满而重复。

## 数量与单位

区分：

- `Number of Items` / 产品数量：包装内独立商品件数。
- `Unit Count`：用于计算单位价格的总量。
- `Unit Count Type`：与商品类型和商品形式兼容的单位枚举，必须从下拉菜单选择。
- 商品净含量/容量：按包装标识填写，不能根据图片估算。

多件装的单位计数应反映整套总量，具体使用容量、重量还是件数取决于当前商品类型定义和实物标签。若页面的有效枚举与真实商品冲突，不要换成不真实的数据来绕过验证。

## 报价与库存

- 父体不填写报价。
- 每个子体填写独立价格、状况、配送模板和可售套数。
- “数量”是可销售包装的套数，不是所有瓶子的总数。
- 自配送与亚马逊配送按照卖家实际方案选择；不能根据页面推荐代替卖家决定。

## 图片

- 主图与销售包装数量完全一致，白底，无水印、边框、促销文字或未包含配件。
- 多件装主图清楚显示准确件数；标题和变体值也必须说明该数量。
- 标签、颜色、瓶型和包装细节应与真实商品一致。
