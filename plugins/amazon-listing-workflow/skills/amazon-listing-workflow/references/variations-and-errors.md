# 变体与错误排查

## 网页创建流程

1. 从原有子体的“编辑商品信息”进入。
2. 美国站前台字段的输入语言设为 `English`。
3. 选择页面实际提供且符合商品差异的变体主题。
4. 添加英文变体值并应用更改。
5. 保留原子体身份；为每个新子体设置唯一SKU、准确图片、价格和库存。
6. 新子体使用自己的有效商品编码，或在已确认GTIN豁免时留空。

如果当前页面没有可用变体主题，不能强行建立不符合类目规则的变体。可使用变体向导、批量上传模板，或向卖家支持确认该商品类型是否支持目标主题。

## 错误处理原则

先按完整错误文本定位属性，不只看错误编号。记录：站点、商品类型、ASIN/SKU、字段路径、当前值、输入语言、变体主题和截图。

### 100720

常见含义是某个可本地化属性的语言数据无效。若错误点名 `package_size_name`：

1. 确认输入语言为 `English`。
2. 使用英文值，并通过候选项或重新创建字段值提交。
3. 如果值最初在中文输入语言下创建，删除旧值后在English环境重新建立。
4. 完全重建仍失败，停止反复修改，改用模板或联系卖家支持修复目录语言元数据。

不要断言所有100720都由同一原因造成；以错误点名的属性为准。

### 90004205

表示提交的属性值不是当前商品类型或相关条件允许的有效值。错误若提到 `item_form.value` 与 `unit_count.type.value`，说明商品形式会限制单位类型。

处理步骤：

1. 核对商品形式是否符合实物，并从下拉菜单点击合法枚举。
2. 核对单位计数和单位类型是否符合包装标签及商品类型。
3. 清空旧值，再从下拉候选项选择；不要只键入显示文字。
4. 不要在 `Fl Oz`、`Ounce`、`Count` 之间无休止试值，也不要把液体、粉末或气雾剂互相改写来绕过验证。
5. 两到三次基于事实的组合仍失败时，停止网页重试，使用批量上传模板获取处理报告，或联系卖家支持要求目录团队检查产品类型定义和原ASIN属性。

## 批量模板替代流程

在“批量上传商品”中下载与实际商品类型匹配的最新美国站模板。创建一行父体和各子体行，按模板下拉值填写父子关系、关系类型和变体主题。上传后查看处理报告，以报告中的字段名和允许值继续修正。

模板会更新，不能凭记忆编造列名或枚举。用户提供模板后，读取实际工作表标题、数据定义和有效值页，再逐列填写。

## 卖家支持材料

提供ASIN、SKU、Marketplace ID、商品类型、完整错误文本、截图、已经测试的真实值，以及“这些值均由下拉菜单选择但仍被拒绝”的说明。请求 Catalog Team 检查属性映射或语言元数据。
